## Where New Content Goes — apply this before writing to AGENTS.md or any skill

Whenever there's something worth remembering — a convention, landed feature, fix, standing instruction, or a `/savememory` call — decide where it goes first. Default: **if unsure, it is NOT restart-critical.** Skills and archive files cost nothing until read; AGENTS.md costs tokens every session. Put full detail in a skill; leave a one-line pointer here.

- **"Where We Left Off" is only for genuinely unfinished jobs** (open decision, unreviewed background job, half-applied fix) the next session must resume mid-thread. Test: "if I deleted this, would the next session be missing something?" Completed work gets nothing here.
- **Follow-up work generated by a session** is backlog: short pointer in Next Session Tasks, full detail in `posit/task_backlog.md`.
- Keep any "Where We Left Off" entry to a few lines. `/savememory` always writes the full narrative to `posit/session_history/`.
- When a finding resolves or a fix lands, **delete its "Where We Left Off" entry outright.**
- **Topic-specific / conditionally relevant** (convention, script logic, landed feature, data-source reference) -> matching skill in `.posit/assistant/skills/`. Append to an existing skill if its `description` covers the topic; else create one. Update `description` frontmatter if triggers change. Wait until a topic is stable before promoting it; active investigations stay in archive/session-history.
- **Reference-style skills are structural snapshots, not session logs** — overwrite entries to describe *current* behavior; bug stories go to `posit/archive/*.md` or `posit/session_history/*.md` with one pointer.
- **Backlog / not-yet-active tasks** -> `posit/task_backlog.md` (see `session-protocol` skill).
- **"Landed in source, not yet run/verified" backlog items get a one-liner**, not narrative. Template: `session-protocol` skill.
- **Pure historical narrative** -> `posit/archive/*.md` or `posit/session_history/`, never AGENTS.md.

If AGENTS.md exceeds ~100 lines, something was misrouted — find and move it.
