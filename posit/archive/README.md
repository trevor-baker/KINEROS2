# Archive

Topic-organized narrative snapshots: root-cause stories, investigation detail,
full pending-verification writeups, and superseded/landed session narrative
moved out of AGENTS.md. Read only when explicitly needed (e.g. investigating
why a past decision was made) — not loaded automatically.

Naming convention: `YYYYMMDD-HHMM-short-topic-description.md` — include the time,
not just the date, for the same multi-contributor/multi-branch reason
`session_history` filenames are timestamped rather than sequentially numbered
(see `session-protocol` skill). Multiple items from the same session/topic can
share one file if related (see `session-protocol` skill's "Pending-Verification
Item Style" and "Bundling" sections for when to split vs. combine).

Full protocol: `.posit/assistant/skills/session-protocol/SKILL.md`.
